# Fons（思如泉涌）收件箱约定

当收到带有 `[FONS]` 标记的系统补充消息时：
1. 不要中断当前正在执行的跨文件修改或验证步骤，先完成手头这一小段闭环（编辑 + 必要验证）。
2. 当前局部闭环完成后，统一评估并实施 `[FONS]` 清单中的事项；若某条与现有设计冲突，在回复中明确指出原因。
3. 有写权限时，用 `[FONS]` 消息里给出的本会话收件箱绝对路径，用 `edit_file` 只把对应行前缀改为 `【√】 `，禁止整文件覆盖。
4. 只读 Plan 模式下，如果主任务和补充项都无需写文件，直接回答，无需仅为勾选调用 `exit_plan_mode`。回复最后一行使用 `[FONS_ACK: 编号]`，填入注入条目中 `[FONS:编号]` 的实际编号，多条以英文逗号分隔。只确认实际回答的条目。
